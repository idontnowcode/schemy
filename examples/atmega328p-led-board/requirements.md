# ATmega328P 상태 LED 보드

USB 5V 어댑터로 동작하는 작은 MCU 보드.

- 전원: 2핀 커넥터로 5V 입력 (보드 전체 100mA 이하)
- MCU: ATmega328P-AU, 16MHz 크리스탈. 부트로더가 들어 있는 칩을 쓰고 UART로 프로그래밍한다.
- 5V 입력단에 10µF 벌크 콘덴서
- 상태 LED 1개: PB5(Arduino D13)에서 저항을 거쳐 GND로, 약 3mA
- 전원 LED 1개: 5V가 들어오면 켜짐, 약 3mA
- PC 연결: 3핀 헤더(TXD, RXD, GND), 5V 레벨 USB-UART 어댑터 사용. 헤더에 DTR이 없으므로 업로드 직전에 누를 리셋 버튼 1개
- 칩 저항·콘덴서는 0603(10µF만 0805), 커넥터는 2.54mm 핀헤더, 버튼은 6mm 택트 스위치
