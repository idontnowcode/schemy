# 12V DC 모터 드라이버 (DRV8871)

사용자 요청: "모터제어 회로 하나 그려줘봐. 검토까지 끝내고 리포트도 첨부"

요청에 모터 종류·전압·전류·제어 방식이 없어서 다음과 같이 정했습니다(근거는 `rationale.md`의 'AI가 정한 것').

- 모터: 12V 브러시 DC 모터, 연속 1A 이하, 기동·구속 시 2A 남짓으로 제한
- 전원: 12V DC 어댑터(단자대), 역전압·과전류·서지 보호
- 제어: 외부 컨트롤러(MCU 등)의 3.3V/5V 신호 2개로 정회전·역회전·브레이크·PWM 속도 제어
- 출력: 모터 단자대
- 표시: 12V 전원 LED
- 회로도의 블록 설명과 주요 사양은 영문 주석으로 표시
