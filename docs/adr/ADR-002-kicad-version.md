# ADR-002: 지원 KiCad 버전 고정

- 상태: **채택(Accepted)**. 2026-11-04 사용자가 검토 제안 반영을 지시해 기획서 v1.2 18장에 결정으로 기록.
- 날짜: 2026-11-03 (제안), 2026-11-04 (채택)

## 배경

`.kicad_sch` 파일 형식은 KiCad 메이저 버전마다 바뀐다. 새 버전은 예전 파일을 읽지만, 예전 버전은 새 파일을 읽지 못한다. ERC를 CLI로 돌리는 `kicad-cli sch erc`는 KiCad 8부터 있다.

2026-11-03에 확인한 사실:

| 항목 | 값 |
|---|---|
| 최신 안정판 | KiCad **10.0.8** (Docker Hub `kicad/kicad:10.0.8`, 2026-10-30) |
| KiCad 10 회로도 파일 버전 | `20260306` (10.0.8의 `sch upgrade` 출력) |
| KiCad 10 심볼 라이브러리 버전 | `20251024` |
| Ubuntu 24.04 apt 패키지 | 7.0.11. `sch erc`가 없어 이 PoC에는 쓸 수 없음 |

## 결정

- **KiCad 10.0.x를 지원 버전으로 고정한다.** 생성 파일 형식은 `20260306`이다.
- 검증 기준 버전은 10.0.8이다. CI와 개발용 Docker 이미지는 `kicad/kicad:10.0.8` 태그로 고정한다.
- 내장 심볼(lib_symbols)도 같은 버전의 라이브러리에서 가져온다. 버전이 섞이면 ERC가 `lib_symbol_mismatch`를 낼 수 있다.

## 영향

- 생성된 파일은 **KiCad 9 이하에서 열리지 않는다**. KiCad 9를 지원해야 한다면 KiCad 9 라이브러리와 형식 `20250114`로 생성하는 별도 프로필이 필요하다.
- 10.0.x 패치 버전이 바뀌면 통합 테스트(`pytest -m kicad`)를 다시 돌린다. golden 파일 비교와 round-trip 테스트가 형식 변화를 잡는다.
- Windows 기본 설치 경로는 `C:\Program Files\KiCad\10.0\`이다(`bin\kicad-cli.exe`, `share\kicad\symbols`). 이 경로는 아직 Windows에서 직접 확인하지 않았다.
- 2026-11-04 사용자 PC의 KiCad GUI에서 생성 회로도가 열리는 것을 확인했다(프로젝트로 열 때 경고 없음).
