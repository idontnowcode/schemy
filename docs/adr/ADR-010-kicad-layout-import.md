# ADR-010: KiCad에서 옮긴 배치 가져오기 (외부 수정 가져오기 1단계)

- 상태: **채택(Accepted)**
- 날짜: 2026-11-05
- 관련: 기획서 13장 "양방향 편집 데이터 충돌"(초기에는 외부 수정 읽기 전용 → 이후 명시적 import/diff), 20장 후속 3번, IR 0.6.0

## 결정

1. **가져오는 것은 배치뿐이다.** 부품의 위치, 회전, 좌우 반전만 가져온다. 배선, 라벨, 전원 심볼은 생성기가 다시 그린다. 연결은 파일에서 읽지 않는다. 연결의 기준은 언제나 IR이다.
2. **짝짓기는 `AICS_ID`로 한다.** 생성기는 IR 부품마다 숨은 필드 `AICS_ID`를 심볼에 적는다. 기호(R1)는 바뀔 수 있으므로 기호로 추측하지 않는다.
   - `AICS_ID`가 없는 심볼(KiCad에서 추가한 부품)은 가져오지 않고 제안 설명에 적는다.
   - 다중 유닛 부품은 1번 유닛만 가져온다. IR은 부품마다 위치 하나를 가진다. 나머지 유닛은 자동 배치로 둔다.
3. **IR `Placement.mirror`(0.6.0):** 좌우 반전(KiCad `mirror y`)을 담는다. KiCad의 `mirror x`는 `mirror y` + 180° 회전과 같으므로 그렇게 바꿔 저장한다.
   - 변환 순서는 **회전 후 반전**이다. KiCad 10.0.8로 90°·270° 회전과 반전을 함께 건 부품의 연결을 확인했다.
   - 이전 생성기는 반전 후 회전으로 계산했지만, 자동 배치는 반전을 0°·180° 부품에만 써서 결과가 같았다.
4. **바꾸는 길은 하나다.** 가져오기는 `move` 연산의 제안(출처 `kicad_layout`)을 만든다. 비교 표에는 옮겨진 부품만 나온다.
   - 승인하고 다시 생성하면 바깥에서 고친 출력 파일을 덮어쓴다. 그 내용은 이미 회로에 들어왔기 때문이다.
   - 「자동 배치로 되돌리기」는 고정 배치를 모두 지우는 제안이다.
5. **조건:** 출력 회로도가 현재 revision에서 생성된 것이어야 한다. 그렇지 않으면 위치를 엉뚱한 부품에 붙일 수 있어 거부한다(`OUTPUTS_STALE`). 바뀐 것이 없으면 `NO_LAYOUT_CHANGES`다.

## 다음 단계 후보

- 다중 유닛의 유닛별 위치(IR에 유닛 배치 추가).
- KiCad에서 바꾼 연결을 IR 패치 제안으로 가져오기(Netlist 비교 기반). 연결 변경은 사람이 비교 표로 확인해야 하므로 별도 ADR에서 정한다.
