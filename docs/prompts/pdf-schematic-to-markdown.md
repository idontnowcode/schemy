# PDF 회로도 → Markdown 변환 프롬프트 (코파일럿용)

- 버전: 회로도 MD v0.1 (초안, 2026-11-04)
- 목적: PDF 회로도를 AI(코파일럿 등)로 읽혀 **정해진 형식의 Markdown 파일**로 옮겨 적는다. 앱은 나중에 이 파일을 읽어 Circuit IR로 바꾸고, 그 IR로 KiCad 회로도를 다시 만든다.
- 상태: 앱에 구현됨(Phase 1.5). **회로 (IR)** 탭의 **회로도 MD 가져오기**로 이 형식의 파일을 넣는다. AI 기능을 켜면 **PDF 가져오기 (AI)**가 같은 프롬프트로 Gemini에게 변환을 맡긴다(앱이 쓰는 프롬프트: `ai_engine/prompts/pdf_schematic_to_md.txt`, 아래 본문과 같은지 테스트로 확인).

## 사용 방법

1. **보안부터 확인한다.** 회사 회로도를 외부 AI 서비스에 올려도 되는지 사내 규정을 먼저 확인한다.
2. **PDF를 준비한다.**
   - EDA 도구에서 내보낸 PDF(글자를 선택할 수 있는 PDF)가 가장 정확하다.
   - 스캔본이거나 AI가 선을 잘 못 읽으면, 페이지를 고해상도 이미지(최소 200 dpi, 복잡하면 영역을 잘라서)로 만들어 함께 첨부한다.
3. **코파일럿에게 맡긴다.** 아래 "프롬프트 본문"을 통째로 붙여 넣고 PDF(또는 이미지)를 첨부한다.
4. **결과를 직접 검토한다.** "7. 불확실 항목"과 "8. 자체 점검"을 반드시 확인한다. IC의 핀 번호와 극성 부품의 방향은 원본과 대조한다.
5. **파일로 저장한다.** 결과를 `회로이름.md`로 저장한다.
6. **앱에 넣는다.** 보드를 고르고 **회로 (IR)** 탭에서 **회로도 MD 가져오기**를 누른다. 앱이 KiCad 라이브러리 핀과 대조해 틀린 핀 번호를 걸러내고, 결과 보고서와 함께 편집기에 불러온다. 검토한 뒤 **저장**해야 revision이 생긴다.

> AI가 옮겨 적은 회로도는 틀릴 수 있다. 특히 IC 핀 번호, 선의 교차와 접속의 구분, 숨겨진 전원 핀에서 자주 틀린다.
> 앱은 가져온 회로를 "미확인"으로 두고, 불확실 항목이나 경고(핀 이름 충돌, 빠진 핀, 4장과 3장 불일치 등)가 하나라도 있으면 "검토 필요"로 둔다. 사람이 확인하기 전에는 "Engineer reviewed"로 바꾸지 않는다.

## 프롬프트 본문

아래 블록 전체를 복사해서 쓴다.

````text
당신은 전자회로 회로도를 한 글자도 틀리지 않게 옮겨 적는 엔지니어입니다.
첨부한 PDF 회로도를 아래 "회로도 MD v0.1" 형식의 Markdown 파일 하나로 옮겨 적으세요.
이 파일은 프로그램이 읽어서 KiCad 회로도로 다시 그리므로, 형식과 규칙을 정확히 지켜야 합니다.

[절대 규칙]
1. 추측하지 마세요. 읽을 수 없거나 확실하지 않은 값은 `?`로 쓰고, "7. 불확실 항목"에 위치(페이지, 대략적인 영역)와 이유를 적으세요.
2. 연결은 반드시 "부품 기호.핀 번호"(예: U1.14, R3.2) 기준으로 적으세요. 핀 번호는 PDF에 인쇄된 숫자를 그대로 옮기세요. 데이터시트나 일반 지식으로 핀 번호를 채워 넣지 마세요.
3. 핀 번호가 인쇄되지 않은 부품:
   - 극성이 없는 2핀 부품(저항, 일반 콘덴서, 인덕터, 퓨즈)은 핀 번호를 1, 2로 쓰고 비고에 "번호 미표시"라고 적으세요.
   - 극성이 있는 부품(다이오드, LED, 전해·탄탈 콘덴서, 트랜지스터, 레귤레이터 등)은 핀 번호를 `?`로 두고, 핀 이름 칸에 그림에서 알 수 있는 이름(A/K, +/-, B/C/E, G/D/S, IN/OUT/GND 등)을 쓰세요.
4. 선이 교차하기만 하고 접속점(굵은 점)이 없으면 연결이 아닙니다. 접속점이 있거나 선이 T자로 만날 때만 연결로 보세요. 애매하면 불확실 항목에 적으세요.
5. 이름이 같은 Net 라벨, 같은 전원 기호(VCC, +5V, +3V3, GND 등), 페이지 간 연결 기호는 모두 같은 Net입니다.
6. 이름이 없는 Net은 N_001, N_002 … 처럼 번호를 붙이세요.
7. 한 부품이 여러 조각(유닛 A/B, 전원 유닛 등)으로 나뉘어 그려져 있어도 같은 부품 기호로 합쳐서 적으세요. 그림에 보이지 않는 전원 핀이 있을 것 같으면 지어내지 말고 불확실 항목에 적으세요.
8. 모든 부품의 모든 핀이 "3. 핀 연결" 표에 한 줄씩 있어야 합니다. 연결되지 않은 핀은 Net 칸에 NC(그림에 미연결 X 표시가 있을 때) 또는 `?`(표시가 없을 때)를 쓰세요.
9. 표의 열 이름과 순서를 바꾸지 마세요. 표 칸 안에 `|` 문자를 쓰지 마세요. 값의 단위는 PDF 표기를 따르세요(예: 10k, 4.7uF, 330R).
10. "4. Net" 표는 "3. 핀 연결" 표에서 만든 요약입니다. 두 표가 서로 맞는지 직접 대조한 뒤 "8. 자체 점검"을 채우세요.
11. 부품이 많아서(대략 60개 이상) 한 번에 다 적기 어렵다면 페이지별로 나눠서 출력하세요. 이때 각 출력 맨 위 "1. 정보"에 페이지 범위를 적고, "6. 페이지 간 연결"을 빠짐없이 채우세요.
12. 제조사와 제조사 품번은 PDF(부품 표, BOM, 부품 옆 표기)에 적혀 있을 때만 쓰세요. 값이나 패키지로 짐작해 채우지 마세요.
13. Markdown 파일 내용만 출력하세요. 앞뒤에 설명 문장을 붙이지 마세요.

[KiCad 심볼 칸 작성 기준]
확실한 일반 부품만 아래처럼 적고, 나머지는 비워 두세요(프로그램이 채웁니다).
- 저항 Device:R, 일반 콘덴서 Device:C, 극성 콘덴서 Device:C_Polarized, 인덕터 Device:L
````

## 형식 규칙 (가져오기 기능이 지키는 기준)

앱의 가져오기 기능(`circuit_core/schematic_md.py`)은 이 규칙대로 읽는다. 오류가 하나라도 있으면 IR을 만들지 않는다.

| 회로도 MD | Circuit IR | 처리 |
|---|---|---|
| 2장 `기호` | `components[].reference` | 중복이면 오류 |
| 2장 `값` | `value` | `?`면 오류가 아니라 "검토 필요" |
| 2장 `KiCad 심볼` | `symbol_id` | 비어 있으면 `종류`로 추정(저항→`Device:R`, 전해 콘덴서→`Device:C_Polarized`, 커넥터→`Connector_Generic:Conn_01x<핀 수>` 등)하고 알림으로 표시. 추정할 수 없으면 `Unknown:<기호>`로 두고 경고 |
| 2장 `패키지` | `footprint_id` | R/C/L/LED의 칩 크기(0402~1206)는 KiCad 표준 풋프린트로 추정(예: `Resistor_SMD:R_0603_1608Metric`). 보유 자재 목록과 대조할 때 사용 |
| 2장 `제조사` | `manufacturer` | 선택 열(없어도 가져옴). 품번과 함께 있으면 데이터시트를 찾는 근거가 됨 |
| 2장 `제조사 품번` | `manufacturer_part_number` | |
| 3장 각 행 | `pins[]` + `nets[].nodes[]` | 연결의 기준. 한 핀이 두 Net에 있으면 오류. 2장 핀 수보다 적으면 나머지 핀을 미연결로 추가하고 경고 |
| 3장 `핀 번호`가 `?` | — | KiCad 라이브러리의 핀 이름으로 번호를 찾고, 찾은 근거를 기록. 못 찾으면 오류 |
| 3장 `Net`이 `NC`/`?` | 연결 없음 | `?`는 "검토 필요" |
| 4장 | — | 3장과 대조하는 확인용. 다르면 경고(`NET_TABLE_MISMATCH`). IR에는 3장만 반영 |
| Net 이름 | `nets[].name` | 공백 등 쓸 수 없는 글자는 `_`로 바꾸고 알림(`LED A` → `LED_A`) |
| 2장 `페이지` | `sheets` | 페이지가 둘 이상이면 페이지마다 시트(`p1`, `p2`, …)를 만든다 |
| 7장 | `validation.notes` | 항목이 하나라도 있으면 상태를 `needs_review`로 |
| 8장 | — | 부품 수·Net 수·행 수를 다시 세어 다르면 경고 |
| 출처 | `pin_map_evidence.source` | "PDF 전사: <파일>, p.<페이지>", 상태 `unverified` |

## 예시: LED + 저항 + 커넥터 (`examples/led-resistor-connector`)
